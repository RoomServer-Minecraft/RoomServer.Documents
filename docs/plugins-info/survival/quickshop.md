# QuickShop (ショップシステム)

## QuickShopとは？

「QuickShop」とは、チェストを使って簡単にショップを作成・利用出来るプラグインです。

## 使い方

自分のアイテムを販売したり、他のプレイヤーが作成したショップからアイテムを購入したり出来ます。

### ショップの作り方

1. **チェストを設置**し、売りたいアイテムを中に1つ以上入れます。
2. **アイテムを手に持たず**、チェストを左クリックします。
3. チャット欄に「価格」を入力するように指示が出るので、**売りたい単価**を入力します。
4. これでショップが完成します！チェストの上に販売アイテムのプレビューが表示されます。

### 買い方

1. ショップのチェストを**右クリック**します。
2. 購入するかどうかの確認が出るので、購入したい場合はチャット欄、またはGUI（設定による）で操作します。

### ショップ情報の確認
ショップを**左クリック**すると、在庫などの詳細情報を確認することが出来ます。

### ショップの削除
ショップのチェストを破壊することで、ショップを削除することが出来ます。
