# Jobs (職業システム)

## Jobsとは？

「Jobs」とは、職業ごとに決められた特定の行動（伐採師なら木を切る、採掘鉱石を掘るなど）を行うことで、通貨や経験値を稼ぐためのプラグインです。  
就職中の職業に関連した作業を行うたびに、報酬を得る事が出来ます。

{% hint style="success" %}
**Jobsの主な特徴は次の通りです**

* **働いて稼ぐ**: 自分のプレイスタイルに合った職業でサーバー内通貨を稼げます。
* **レベルアップ**: 作業を続けることでレベルが上がり、報酬額がアップします。
* **複数加入**: 複数の職業に同時に就く事が出来ます。
{% endhint %}

## 使い方

* **職業の確認**: `/jobs browse`  
ここから就職することも出来ます。

* **現在の職業の統計表示**: `/jobs stats`

* **職業を辞める**: `/jobs leave [職業名]`

## 注意点

* 一度に就職出来る職業は、合計**3つ**までです。
* 離職してしまうと、職業スキルのレベルが**リセット**されます。

## 職業一覧と説明

| 職業名 | 役割 |
| :--- | :--- |
| **醸造家** | 木を伐採することで報酬が得られます。 |
| **建築家** | ブロックを設置することで報酬が得られます。 |
| **Woodcutter (伐採師)** | 木を伐採することで報酬が得られます。 |
| **Miner (採掘師)** | 石や鉱石を掘ることで報酬が得られます。 |
| **Farmer (農家)** | 農作物を収穫、種を植えることで報酬が得られます。 |
| **Hunter (ハンター)** | モンスターや動物を倒すことで報酬が得られます。 |
| **Fisherman (漁師)** | 魚を釣ることで報酬が得られます。 |

※`/jobs browse`からGUIを開いて、各職業の詳細（行動に応じた金額）を確認する事が出来ます。
