# Jobs (職業システム)

## Jobsとは？

「Jobs」とは、特定の行動（木を切る、鉱石を掘るなど）を行うことで、お金や経験値を稼ぐことができるシステムです。  
プレイヤーは複数の職業に就くことができ、その職業に関連した作業を行うたびに報酬が得られます。

{% hint style="success" %}
**Jobsの主な特徴は次の通りです**

* **働いて稼ぐ**: 自分のプレイスタイルに合った職業でサーバー内通貨を稼げます。
* **レベルアップ**: 作業を続けることでレベルが上がり、報酬額がアップします。
* **複数加入**: 複数の職業に同時に就くことができます。
{% endhint %}

## 使い方

自分のなりたい職業を選び、統計を確認するための基本コマンドです。

* **職業の確認・参加**: `/jobs browse`
* **現在の職業の統計表示**: `/jobs stats`
* **職業を辞める**: `/jobs leave [職業名]`

## 職業一覧と説明

代表的な職業は以下の通りです。

| 職業名 | 説明 |
| :--- | :--- |
| **Woodcutter (伐採師)** | 木を伐採することで報酬が得られます。 |
| **Miner (採掘師)** | 石や鉱石を掘ることで報酬が得られます。 |
| **Farmer (農家)** | 農作物を収穫、種を植えることで報酬が得られます。 |
| **Hunter (ハンター)** | モンスターや動物を倒すことで報酬が得られます。 |
| **Fisherman (漁師)** | 魚を釣ることで報酬が得られます。 |
| **Builder (建築家)** | ブロックを設置することで報酬が得られます。 |

※`/jobs browse`からGUIを開いて、各職業の詳細（何をしていくらもらえるか）を確認できます。
