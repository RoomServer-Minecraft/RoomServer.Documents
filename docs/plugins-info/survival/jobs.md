# Jobs (職業システム)

## Jobsとは？

「Jobs」とは、職業ごとに決められた特定の行動（伐採師なら木を切る、採掘家なら鉱石を掘るなど）を行うことで、通貨や経験値を稼ぐためのプラグインです。  
就職中の職業に関連した作業を行うたびに、報酬を得る事が出来ます。

{% hint style="success" %}
**Jobsの主な特徴は次の通りです**

* **働いて稼ぐ**: 自分のプレイスタイルに合った職業でサーバー内通貨を稼げます。
* **レベルアップ**: 作業を続けることでレベルが上がり、報酬額がアップします。
* **複数加入**: 複数の職業に同時に就く事が出来ます。
{% endhint %}

## 使い方

* **職業の確認**: `/jobs browse`  
ここから就職することも出来ます。

* **現在の職業の統計表示**: `/jobs stats`

* **職業を辞める**: `/jobs leave [職業名]`

## 注意点

* 一度に就職出来る職業は、合計**3つ**までです。
* 離職してしまうと、職業スキルのレベルが**リセット**されます。
