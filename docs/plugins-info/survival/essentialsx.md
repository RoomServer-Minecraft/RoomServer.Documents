# EssentialsX

## EssentialsXとは？

「EssentialsX」は、サーバーの基本機能を拡張するためのプラグインです。主に経済関連のコマンドや、プレイヤー同士のユーティリティ機能を提供します。

{% hint style="success" %}
**EssentialsXの主な機能は次の通りです**

* **経済システム**: 所持金の確認や送金が可能です。
* **基本コマンド**: テレポートやメッセージ、情報の確認などの基本操作をサポートします。
* **ユーザー補助**: 初心者から上級者まで使いやすいシンプルなコマンド体系です。
{% endhint %}

## 経済系コマンド

経済鯖での所持金の確認や、他プレイヤーへのお金の送金に使用します。

| コマンド | 説明 |
| :--- | :--- |
| `/bal` (または `/balance`) | 現在の所持金を確認します。 |
| `/gift [プレイヤー名] [金額]` | 指定したプレイヤーに自分のお金を送金します。 |
