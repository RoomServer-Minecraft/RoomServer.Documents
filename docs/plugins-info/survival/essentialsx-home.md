# EssentialsX - ホーム機能

## ホーム機能とは？

自分の好きな場所を「ホーム」として保存できる機能です。
コマンド一つでいつでもホームへと行くことが出来ます。

{% hint style="success" %}
**ホーム機能の主な特徴**

* **簡単登録**: 現在地をホームとして即座にマークできます。
* **高速移動**: どこにいても登録した拠点へ瞬時に戻れます。
* **複数登録可能**: 最大2つまで、好きな名前でホームを使い分けられます。
{% endhint %}

{% hint style="warning" %}
**重要なお知らせ**

* **データ消失**: 2026/03/15のメンテナンスにより、旧来のホームデータは全て消失しています。お手数ですが、再度設定をお願いします。
* **共有機能の廃止**: 以前のシステムにあった「他プレイヤーとのホーム共有（trust機能）」は、セキュリティ上の理由により**廃止されました**。
{% endhint %}

## コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `/sethome [名前]` | 現在地をホームとして登録します。名前を省略すると `home` になります。 |
| `/home [名前]` | 登録したホームへテレポートします。 |
| `/delhome [名前]` | 指定したホームを削除します。 |
| `/homes` | 現在登録されているホームの一覧を表示します。 |

## 使い方とルール

* **登録上限**: 現在、1人につき**最大2個**までホームを設定可能です。
* **上書き**: 同じ名前で `/sethome` を実行すると、古い位置が上書きされます。
* **共有について**: 現在、自分以外のプレイヤーをホームに招待する機能はありません。拠点の場所を教えたい場合は、座標を伝えるなどの方法をご利用ください。
