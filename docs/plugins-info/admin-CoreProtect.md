# admin-CoreProtect

## CoreProtectとは？

「CoreProtect」は、サーバー内で行われたあらゆる操作（ブロックの破壊・設置、チェストの中身の出し入れ、バケツの使用など）を記録し、必要に応じて元に戻したり（ロールバック）、元あった場所に戻したり（復元）することができる強力な管理ツールです。

荒らし被害の調査や復旧には欠かせないプラグインです。

---

## 基本的な使い方

### 1. 調査モード (Inspector)
`/co inspect` または `/co i` を入力すると、調査モードが有効になります。

*   **右クリック**: その場所にあるブロックの設置・破壊履歴、またはチェスト等の操作履歴を表示します。
*   **左クリック**: その場所にあるブロックが以前何であったか、誰が壊したかを表示します。
*   もう一度 `/co i` を入力すると無効化されます。

### 2. ロールバックと復元
広範囲の荒らし被害を修復する際に使用します。

*   **ロールバック (`/co rollback`)**: 指定した条件に一致する操作を**取り消します**。
*   **復元 (`/co restore`)**: 指定した条件に一致する操作を**再現します**。

---

## 主要コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `/co i` | 調査モードの切り替え。 |
| `/co help` | コマンドのヘルプを表示。 |
| `/co l <params>` | 条件を指定して履歴を検索（チャット欄に表示）。 |
| `/co rb <params>` | 条件を指定してロールバックを実行。 |
| `/co rs <params>` | 条件を指定して復元（リストア）を実行。 |
| `/co purge <days>` | 指定日数より前の古いデータを削除。 |
| `/co reload` | 設定ファイルをリロード。 |
| `/co status` | プラグインの状態（データベース接続など）を確認。 |

### ロールバック/検索で使える主なパラメータ
例: `/co rb u:Namek t:1h r:20`

*   **u:<user>** : プレイヤーを指定。
*   **t:<time>** : 時間を指定 (例: `1h` = 1時間, `30m` = 30分, `1d` = 1日)。
*   **r:<radius>** : 半径を指定 (例: `#worldedit` または `r:10`)。
*   **a:<action>** : 特定のアクションを指定 (例: `+block`, `-block`, `click`)。
*   **e:<exclude>** : 特定のブロックを除外。

---

## 注意事項
*   ロールバックは慎重に行ってください。間違えて実行した場合は、`/co restore` で元に戻すことができます。
*   大規模なロールバックを行う際は、サーバーの負荷に注意してください。
