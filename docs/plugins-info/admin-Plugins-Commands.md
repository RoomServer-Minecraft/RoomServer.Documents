# admin-Plugins-Commands

運営スタッフが頻繁に使用する主要プラグインの管理者用コマンド一覧です。

---

## WorldGuard (領域保護)

領域の設定やフラグ（ルール）の変更に使用します。

| コマンド | 説明 |
| :--- | :--- |
| `/rg define [領域名]` | 選択した範囲を新しい領域として定義します。 |
| `/rg addmember [領域名] [プレイヤー]` | 領域にメンバーを追加します。 |
| `/rg removemember [領域名] [プレイヤー]` | 領域からメンバーを削除します。 |
| `/rg flag [領域名] [フラグ] [allow/deny]` | 領域内のルール（建築許可、爆発防止など）を設定します。 |
| `/rg info [領域名]` | 領域の詳細情報を表示します。 |
| `/rg list` | 定義されている領域の一覧を表示します。 |
| `/rg remove [領域名]` | 領域を削除します。 |
| `/wg reload` | WorldGuardの設定をリロードします。 |

## WorldEdit (建築・範囲編集)

大規模な建築や地形変更、範囲コピーに使用します。

| コマンド | 説明 |
| :--- | :--- |
| `//wand` | 範囲選択用の斧を取り出します。 |
| `//set [ブロック]` | 選択範囲を特定のブロックで埋めます。 |
| `//replace [現ブロック] [新ブロック]` | 指定したブロックのみを入れ替えます。 |
| `//copy` | 選択範囲をコピーします（自分の位置が基準）。 |
| `//paste` | コピーした内容を貼り付けます。 |
| `//undo` | 直前の操作を取り消します。 |
| `//redo` | 取り消した操作をやり直します。 |
| `//stack [回数] [方向]` | 選択範囲を指定方向に並べます。 |
| `//brush [形状] [ブロック] [サイズ]` | ブラシ（筆）モードをツールに付与します。 |

## EssentialsX (プレイヤー・サーバー管理)

基本的な管理機能やプレイヤーの処置に使用します。

| コマンド | 説明 |
| :--- | :--- |
| `/ban [プレイヤー] [理由]` | プレイヤーを永久追放します。 |
| `/tempban [プレイヤー] [期間] [理由]` | 期間を指定してプレイヤーを追放します（例: `7d`）。 |
| `/unban [プレイヤー]` | プレイヤーの追放を解除します。 |
| `/mute [プレイヤー] [理由]` | プレイヤーの発言を禁止します。 |
| `/invsee [プレイヤー]` | プレイヤーのインベントリを閲覧・編集します。 |
| `/enderchest [プレイヤー]` | プレイヤーのエンダーチェストを閲覧・編集します。 |
| `/vanish` (または `/v`) | 自分の姿を消し、オンラインリストからも隠します。 |
| `/socialspy` | プレイヤー間の個人メッセージ（/msg）を監視します。 |
| `/jail [プレイヤー] [脱獄先名] [期間]` | プレイヤーを牢屋に送ります。 |

## Jobs (ジョブレベル・データ操作)

プレイヤーのジョブに関するデータの調整に使用します。

| コマンド | 説明 |
| :--- | :--- |
| `/jobs admin setlevel [プレイヤー] [ジョブ名] [レベル]` | 特定のジョブレベルを指定の数値に変更します。 |
| `/jobs admin resetlevel [プレイヤー] [ジョブ名]` | ジョブレベルを初期状態にリセットします。 |
| `/jobs admin expirience [プレイヤー] [ジョブ名] [add/set/take] [数値]` | 経験値を加減または設定します。 |
| `/jobs admin stats [プレイヤー]` | 詳細なジョブ統計情報を表示します。 |
| `/jobs admin reload` | Jobsの設定とデータをリロードします。 |
