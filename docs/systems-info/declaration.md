# 宣戦布告システム説明

この記事では、宣戦布告システムの**遊び方**について説明します。  
**勢力**に分かれて戦争をしたり、勢力の仲間と協力し合う事が出来ます。

## 勢力

このシステムを楽しむために、まずは**勢力に所属**してみましょう。  
（もちろん、ソロプレイでも大丈夫です！）  
既存の**勢力に参加する**方法と、新しく**勢力を立ち上げる**方法があります。

### 勢力に参加する方法

1. 勢力のリーダーに、`/war clan invite <招待するプレイヤーのMCID>` を使用してもらいましょう。

2. `/war clan join <勢力名>` を使用し、勢力に参加しましょう！

### 勢力を立ち上げる方法

あなたが勢力のリーダーです。  
`/war clan create <勢力名>` を使用し、勢力を立ち上げましょう！  
`/war clan disband` で、勢力を解散することも出来ます。

### メンバーを確認する方法

`/war allclan info` を使用し、メンバーを確認することが出来ます。  
なお、**オンラインのプレイヤーのみ**確認が可能なようです。

## 宣戦布告

他の勢力やソロプレイヤーに、宣戦布告をする事が出来ます。  
また、宣戦布告を承認することも出来ます。  

少し勢力のリーダー向けの記事かもしれませんが、  
メンバーの方も目を通しておきましょう。

### 宣戦布告をする方法

1. `/war fukoku` を使用して、GUIを開きましょう。

2. GUI上で、宣戦布告したい**勢力**、または**プレイヤー**を選択します。

3. 完了です！承認を待ちましょう。  
もし取り消したくなった場合は、`/war cancel <戦争ID>` を使用しましょう。

### 宣戦布告を承認、または拒否する方法

`/war accept <戦争ID>` を使い、承認できます。  
また、`/war deny <戦争ID>` を使い、拒否できます。  

戦争IDは布告された時点でチャットに送信されますが、  
見逃してしまった場合は、公式Discordの**宣戦布告チャンネル**をご覧ください。

### 戦争の開始

お互いが戦争に合意した場合の流れを説明します。

1. リーダーは、希望する**参加可能人数を選択**します。  
人数がお互いに違った場合は、2つの中からランダムで抽選されます。

2. 参加人数が決まったら、リーダーは**参加するプレイヤーを選択**します。

3. **5分の準備時間**の後、戦争が開始します！
