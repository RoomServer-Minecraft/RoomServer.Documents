# 経済システム説明

この記事では、経済システムの**遊び方**について説明します。  
**サーバー内通貨**である「￥」が使われています。  
**現実のお金は使われていません**。

## 職業とスキル

お金を稼ぎたい場合、まずは**自分の職業を決める**ことが重要です。

### お金を稼ぐ方法

1. `/jobs browse` を使用し、色々な職業を見てみましょう。  
GUIが開き、職業項目を**左クリック**で職業の概要を見ることが出来ます。  
概要で、**行動で得られるお金の量**を見るのがオススメです。

2. 開いたGUIを使い、**Click to join job** ボタンか、職業項目を**右クリック**して、**就職**しましょう。  
`/jobs join <職業名>` を使用することでも、**就職**が出来ます。

3. 職業に対応した行動をすると、お金を稼ぐことが出来ます！  
自分に合った職業を見つけてみてください。  

4. お金を稼いでいくうちに、**職業のスキルレベル**が上がります。  
スキルレベルが上がると、1回の行動で稼げる金額が増えるようです。

### 離職方法

`/jobs leave <職業名>` を使用して、**離職**が出来ます。

### 注意点

* 一度に就職できる職業は、**3つまで**です。
* 離職してしまうと、これまでに溜めたスキルレベルが**減少**してしまいます。

## 所持金

* `/bal` を使用することで、現在の所持金を確認できます。
* また、 `/baltop` を使用することで、所持金ランキングを確認できます。

## ショップ

ショップを使用すると、**販売**や**買取**をすることが出来ます。  
他プレイヤーが設置したショップで、売買をすることも出来ます。

### ショップの作成方法

1. アイテムを利き手に持ちます。

2. チェストに向かって**左クリック**をします。  
ラージチェストではなく、**チェスト単体**で実行しましょう。

3. 販売したい（または買取したい）アイテムの金額を、**チャットに送信**します。

4. 完了です！  
デフォルトでは販売モードになっています。  
ショップの看板を**右クリック**すると、チャットに取引の設定画面が送信されます。  
チャットに表示された項目をクリックして、取引内容を**カスタム**しましょう！

### 売買方法

他プレイヤーのアイテムを購入したり、または自分のアイテムを売却したい場合は、  
以下の手順で行うことが出来ます。

1. ショップの看板を**左クリック**します。  
エンチャントなどの情報がある場合は、取引内容が表示されるので**確認**しましょう！

2. 取引したい個数をチャットに送信します。

3. 取引完了です！

## ギフトコード

`/gift <ギフトコード>` を使用することで、コードからお金を手に入れることが出来ます。  
月に1回の配布を予定しています。

また、以下のコードは使用できません。
* 自分が一度使用したコード
* 先着人数に達しているコード
