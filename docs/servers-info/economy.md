# 経済鯖

経済鯖では、職業（Jobs）に就いてお金を稼いだり、自分のショップ（QuickShop）を開いたりして、プレイヤー同士で経済活動を楽しむことができます。

## 主要なシステム・プラグイン

| プラグイン名 | 説明 |
| :--- | :--- |
| [**EssentialsX**](../plugins-info/economy/essentialsx.md) | 所持金の確認や送金、ホーム機能などの基本機能を提供します。 |
| [**Jobs**](../plugins-info/economy/jobs.md) | 伐採や採掘などの仕事をしてお金を稼ぐことができます。 |
| [**QuickShop**](../plugins-info/economy/quickshop.md) | チェストを使って簡単にアイテムの売買ができます。 |

{% hint style="info" %}
各プラグインの使い方の詳細は、リンク先のページから確認してください。
{% endhint %}
