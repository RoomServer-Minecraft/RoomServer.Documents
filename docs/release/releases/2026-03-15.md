# 2026年3月15日 リリースノート

## メンテナンス概要

今回のメンテナンスでは、サーバー基盤をMODからプラグインへと変更しました。  
また、経済に関するプラグインを導入しました。  
これに伴い、主要なプラグインの解説ドキュメントを公開・更新しました。

## 新機能とドキュメント

前回のメンテナンスにおける詳細な変更内容は、以下のドキュメントよりご確認いただけます。

### [BlockLocker (チェスト・ドア保護)](../../docs/plugins-info/survival/blocklocker.md)
チェストやドアを保護するプラグインを導入しました。  
対象ブロックに看板を設置するだけで、簡単に保護が可能です。

### [WorldGuard (領域保護)](https://roomserver.blog/docs#plugins-info/survival/worldguard.md)
領域保護に関するドキュメントを、現在のサーバー仕様に合わせて最新化しました。  
以前の説明から変更された正しい情報を記載しています。

### [QuickShop (チェストショップ)](https://roomserver.blog/docs#plugins-info/survival/quickshop.md)
チェストを使ってアイテムを売買できるショップ機能が利用可能になりました。  
誰でも簡単に自分のお店を開くことができます。

### [Jobs (職業システム)](https://roomserver.blog/docs#plugins-info/survival/jobs.md)
経済システムの導入に伴い、好きな「職業」に就くことができるようになりました。  
労働を通じてサーバー内通貨を稼ぐことができます。

### [EssentialsX (経済・基本機能)](https://roomserver.blog/docs#plugins-info/survival/essentialsx.md)
所持金の確認や送金、その他便利なユーティリティ機能が利用可能になりました。

## 重要なお知らせ

ホーム機能のシステムを、以前のCyanSetHome（MOD）からEssentialsX（プラグイン）へと移行しました。  
そのため、以下の点にご注意ください。

{% hint style="danger" %}
**ホームデータ消失のお詫び**  
メンテナンスによるシステム移行に伴い、**旧来のホームデータ（/sethome）はすべて消失しています。**  
大変お手数ですが、再度拠点にてホームの設定をお願いいたします。
{% endhint %}

{% hint style="warning" %}
**ホーム共有機能の廃止**  
以前のシステムに搭載されていた「他プレイヤーとのホーム共有（trust機能）」は、  
サーバーの基盤をプラグインにしたことにより、廃止されました。
{% endhint %}
